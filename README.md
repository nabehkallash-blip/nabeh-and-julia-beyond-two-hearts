# Nabeh & Julia: Beyond Two Hearts

A romantic Flutter adventure game about two hearts finding their way to each other.

## Current milestone

- Flutter project foundation
- Custom dark romantic theme
- Story-inspired home screen
- First playable drag-to-reach-Julia interaction

## Run locally

1. Install Flutter and Android Studio.
2. Run `flutter pub get`.
3. Run `flutter run`.

The project currently uses only Flutter's built-in libraries. More game systems, animations, story chapters, power-ups, sound, secrets, and progression will be added in later milestones.
