# Nabeh & Julia: Beyond Two Hearts

A romantic Flutter adventure about two hearts finding their way to each other.

## Current milestone

- Six story chapters with distinct gameplay mechanics.
- Chapter 1: explore the university and collect eight memories.
- Chapter 2: navigate the message maze and collect fragments.
- Chapter 3: timed lane challenge.
- Chapter 4: solve the four-promises sequence puzzle.
- Chapter 5: chase ten moving letters from NABEH and JULIA and paint them to bring color back to the world.
- Chapter 6: final boss challenge and reunion.
- Redesigned romantic home screen with a six-chapter journey preview.
- Existing photo assets remain the portrait references while full-body character art is being prepared.

## Run locally

1. Install Flutter and Android Studio.
2. Run `flutter pub get`.
3. Run `flutter run`.

The project currently uses Flutter's built-in libraries. Audio and full-body character artwork are the next integration tasks.
